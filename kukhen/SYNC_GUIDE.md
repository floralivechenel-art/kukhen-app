# 📱 Kukhen — Синхронизация данных на Android

## Как работает сохранение данных?

### ✅ Двойное сохранение: Локально + Google Drive

```
Вы добавляете рецепт
    ↓
1️⃣ Сохраняется в database.json (телефон)
    ↓
2️⃣ Автоматически отправляется на Google Drive
    ↓
Данные в безопасности! 🔒
```

### 📍 Локальное хранилище
- **Путь**: `/data/data/com.flet.kukhen/files/database.json`
- **Автоматическое сохранение**: При каждом изменении (добавление, редактирование, удаление рецепта)
- **Работает без интернета**: Если нет сети, данные все равно сохраняются локально

### ☁️ Облачное сохранение (Google Drive)
- **Когда**: Сразу после локального сохранения (фоновый процесс)
- **Где**: В вашем Google Drive под именем `kukhen_backup.json`
- **Требует**: Интернет-соединение и токен авторизации

## 🔐 Разрешения на Android

### Какие разрешения нужны?
На Android при первом запуске приложение попросит разрешения:

| Разрешение | Назначение |
|-----------|-----------|
| **INTERNET** | Синхронизация с Google Drive |
| **READ_EXTERNAL_STORAGE** | Чтение файлов (если нужно импортировать) |
| **WRITE_EXTERNAL_STORAGE** | Запись данных на телефон |

### Как это работает?
- ✅ **Автоматический запрос** при первом запуске приложения
- ✅ **Обязательны для работы** синхронизации
- ✅ **Безопасность**: Приложение запрашивает ТОЛЬКО необходимые разрешения

### Если вы отказали в разрешениях:
1. Откройте **Параметры → Приложения → Kukhen → Разрешения**
2. Включите нужные разрешения вручную
3. Перезагрузите приложение

## 🔄 Кнопки синхронизации

### ☁️ Кнопка облака (вверху справа)
- **Скачивание с Google Drive** на телефон
- Используйте если:
  - Восстанавливаете данные на новом телефоне
  - Хотите вернуться к предыдущей версии

### Автоматическая загрузка
- **Происходит автоматически** при каждом сохранении
- Не нужно ничего нажимать — всё работает в фоне
- Если ошибка — вы увидите сообщение

## 🚀 Рекомендации

### Что делать регулярно?
- ✅ Проверять интернет-соединение для синхронизации
- ✅ Периодически проверять синхронизацию кнопкой облака
- ✅ Хранить сильный пароль для Google-аккаунта

### Если что-то не синхронизируется?
1. Проверьте интернет
2. Убедитесь, что разрешения включены
3. Попробуйте кнопку облака вручную
4. Перезагрузите приложение

### Если потеряли данные?
- Нажмите ☁️ кнобку — восстановит последнюю копию с Google Drive
- Локальные данные не удаляются

## ⚙️ Для разработчиков

### Файлы конфигурации
- `buildozer.spec` — конфигурация разрешений для Android
- `requirements.txt` — зависимости (включая google-auth)
- `google_drive.py` — логика синхронизации

### Отключить автосинхронизацию?
Найдите в `main.py` функцию `auto_sync_to_drive()` и закомментируйте вызовы если нужно.

### Проверить логи синхронизации?
```python
# В main.py есть обработчик ошибок:
except Exception as err:
    print(f"Фоновая синхронизация пропущена: {err}")
```
