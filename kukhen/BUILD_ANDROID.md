# 🔧 Инструкция по сборке Android приложения Kukhen

## Требования

- **Python 3.11+**
- **Java Development Kit (JDK) 11+**
- **Android SDK**
- **Buildozer**

## Установка зависимостей

### 1. Установите Buildozer и зависимости
```bash
pip install buildozer cython
```

### 2. Установите Python зависимости из requirements.txt
```bash
pip install -r requirements.txt
```

## Конфигурация (уже готова)

Файл `buildozer.spec` уже содержит:
- ✅ Все необходимые разрешения для Android
- ✅ Поддержку Google Drive синхронизации
- ✅ Настройки для работы на устройствах Android 5.1+

## Сборка приложения

### Для первой сборки (длительный процесс)
```bash
buildozer android debug
```
Это создаст файл:
```
bin/kukhen-1.0-debug.apk
```

### Для последующих сборок (быстрее)
```bash
buildozer android debug -- --skip-update
```

## Установка на устройство

### Способ 1: USB-кабель
```bash
adb install bin/kukhen-1.0-debug.apk
```

### Способ 2: Через файловый менеджер
1. Скопируйте `.apk` файл на телефон
2. Откройте файл с помощью установщика
3. Подтвердите установку

## Настройка разрешений

После установки:
1. Откройте приложение Kukhen
2. Примите запрос разрешений (INTERNET, READ/WRITE STORAGE)
3. Приложение готово к работе!

## Синхронизация с Google Drive

### Первая авторизация
1. Приложение запросит доступ к Google Drive
2. Браузер откроет страницу Google (может быть на компьютере)
3. Разрешите доступ
4. Токен сохранится в файл `token.json`

### Автоматическая синхронизация
- ✅ Каждое сохранение рецепта автоматически отправляется на Google Drive
- ✅ Локальные данные всегда в безопасности
- ✅ Восстановление кнопкой ☁️ в приложении

## Частые проблемы

### Ошибка "sitepackages.zip"
- **Причина**: Кэш googleapiclient в ZIP архиве
- **Решение**: Уже исправлено в `google_drive.py` (используется отдельная директория кэша)

### Разрешения не запрашиваются
- **Причина**: Android 6.0+ требует явного запроса
- **Решение**: Вызовите `request_android_permissions()` в `main()` (уже сделано)

### Синхронизация не работает
1. Проверьте интернет-соединение
2. Убедитесь, что разрешения включены
3. Проверьте, что `token.json` существует
4. Попробуйте кнопку ☁️ для восстановления

## Релизная версия (Production)

Для релиза на Google Play:
```bash
buildozer android release
```

Нужно будет:
1. Создать ключ подписи: `jarsigner`
2. Подписать APK
3. Загрузить в Google Play Console
