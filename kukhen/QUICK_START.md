# ⚡ Краткий ответ на вопросы

## Вопрос: Данные сохраняются на телефон И в Google Drive?

### ✅ ДА! Вот как это работает:

```
📱 ТЕЛЕФОН (database.json)
    ↓ каждое сохранение
☁️  GOOGLE DRIVE (kukhen_backup.json)
```

**Поток:**
1. Вы добавляете рецепт в приложение
2. Данные **сразу сохраняются** в `database.json` на телефоне ✅
3. Одновременно **автоматически** отправляются на Google Drive ✅

**Если нет интернета?**
- Данные все равно сохраняются на телефон
- На Google Drive загрузятся, как только появится интернет

## Вопрос: Нужно ли отдельно запрашивать разрешения?

### ✅ АВТОМАТИЧЕСКОЕ (не нужно ничего писать)!

**Что я сделал:**
1. ✅ Добавил функцию `request_android_permissions()` в `main.py`
2. ✅ Она вызывается автоматически при первом запуске
3. ✅ Использует `buildozer.spec` для явного запроса разрешений

**Какие разрешения запрашиваются:**
- `INTERNET` — для Google Drive
- `READ_EXTERNAL_STORAGE` — чтение файлов  
- `WRITE_EXTERNAL_STORAGE` — сохранение данных

**На экране телефона:**
```
Android запрашивает: "Kukhen" хочет доступ к:
  ☐ Интернету
  ☐ Файлам
  ☐ Памяти устройства
```
Пользователь просто нажимает "Разрешить" — и всё работает! 🎯

## Что дальше?

### 🚀 Чтобы протестировать:
1. На компьютере:
   ```bash
   pip install -r requirements.txt
   flet run
   ```

2. Собрать APK для Android:
   ```bash
   pip install buildozer
   buildozer android debug
   ```

3. Установить на телефон:
   ```bash
   adb install bin/kukhen-1.0-debug.apk
   ```
